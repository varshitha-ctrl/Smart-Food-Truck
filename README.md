# Smart Food Truck Tracking System

A web-based Smart Food Truck Tracking System that helps users locate nearby food trucks using an interactive map.

## Features

- Interactive food truck location tracking
- Nearby food truck visualization
- Interactive map with truck markers
- User-friendly and responsive interface
- Location-based food truck information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap
